# 09-evaluation — 评估体系配套代码

某企业 诊断 Agent 质量评估基线计算。基于 mock 对话数据计算任务完成率、工具调用准确率、响应延迟、成本效率四项指标，与预设基线对比，无需真实 LLM 调用。

对应文档：[评估体系](../../docs/docs/09-evaluation/index.md)

---

## 运行演示

```bash
MOCK_MODE=true python eval_metrics.py
```

---

## 某企业 评估基线

| 指标 | 目标值 |
|------|--------|
| 任务完成率 | ≥ 85% |
| 工具调用准确率 | ≥ 90% |
| 平均响应延迟 | ≤ 30s |
| 成本效率 | ≤ 2000 tokens/次 |
